# trykklar

`trykllar` (Danish for 'ready-to-print') is a free and open source PDF preflight engine for
packaging artwork.

## Features

- Lenient Content Walker: Fully typed iterator over each content stream operator including graphics
  state handling.
- Nested content walking: From Page, FormXObject and TilingPattern
